# Thai Herb Cooperative-Superior-AgriTech Joint Steering Committee Charter

## Governance Structure
- **Chairperson**: [CEO - Supervisor-AgriTech]
- **Members**:
  - 3 from Supervisor-AgriTech (CEO, CTO, Head of R&D)
  - 3 from Thai Herb Cooperative (Chairperson, Technical Director, Operations Director)

## Responsibilities
1. Strategic Direction
   - Oversee partnership alignment with mission
   - Approve cultivation protocol changes
   - Monitor 90-day integration milestones

2. Technical Oversight
   - Review AI system co-development
   - Approve sensor deployment plans
   - Monitor data lake integration

3. Quality Assurance
   - Review organic/GAP certification processes
   - Approve outcome-linked pricing metrics
   - Monitor traceability standards

4. Financial Management
   - Track joint investment fund
   - Review premium pricing performance
   - Approve revenue-sharing calculations

## Decision-Making Process
- Consensus for strategic decisions
- Majority vote for operational items
- Cooperative member input required for policy changes

## Meeting Calendar
- Biweekly operational meetings (30 mins)
- Monthly farmer network reviews (1 hr)
- Quarterly strategic roundtables (2 hrs)

## IP & Data Framework
- Shared IP for AI-driven quality system
- Cooperative owns farm data, Supervisor-AgriTech owns analytics
- Joint data lake for traceability and outcome correlation

## Dispute Resolution
- Mediation with cooperative member representative
- Escalation to governing body if unresolved within 15 days
